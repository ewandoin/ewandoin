# Portfolio starter

## Put it online
1. On GitHub, create a repo named `yourusername.github.io`.
2. Upload everything in this folder (Add file > Upload files).
3. Settings > Pages > deploy from the `main` branch. Your site is live in a minute or two.

## Add your images (put them in `images/`)
- Homepage rows use cut-out photos with transparent backgrounds, saved as PNG or WebP:
  `hiker-hero.png`, `clog-hero.png`, `erikyvon-hero.png`, `bikebag-hero.png`, `leatherfootwear-hero.png`, `barnina-hero.png`.
  (If you use WebP, change `.png` to `.webp` in `index.html`.)
- Project pages use `hiker-1.jpg` to `hiker-4.jpg` (same pattern for each project). Keep files under about 300 KB each.
- Until an image exists, its spot shows a placeholder with the file name.

## Edit your details
- Name, email, intro text and CV: top of `site.js`. They show in the right-hand panel on every page.
- CV download: add `cv.pdf` to this folder.
- Colours: top of `style.css`.
- New project: copy a project page (e.g. `hiker.html`), rename it, edit the text and image names, then copy a `<article class="row">` block in `index.html`.
